# Python 기반 검토 파일럿 배포

## 목적과 결정

사용자가 승인한 PC별 Python 실행 방향과 2026-09-15 후속 진행 요청에 따라,
통합 검토 Excel의 개발용 Node/Artifact Tool 의존성을 제거한다.
현재 4시트/12행 Summary/표시 원문/검토 필요 상태는 유지한다.
기존 결과와 새 결과를 전 셀 대조하며, DB 업무 판정이나 XML 추출 규칙은 이번 범위가 아니다.

검토한 선택지는 개발용 작성 환경 번들, Python 작성기, Excel 설치 자동화다.
담당자에게 이미 Python이 있으므로 기존 의존성 openpyxl을 쓰는 프로그램 작성기가 가장 간단하다.
Artifact Tool은 기존 결과 대조와 개발 시각 검증에 사용하며 배포 ZIP에는 포함하지 않는다.
이 결정은 배포 소프트웨어 구현에 해당한다. 별도 사용자 재승인 없이 승인된 후속 작업으로 진행한다.

## 동작

- `CombinedReviewRequest(pdf, output)`과 UI/CLI의 기본 실행은 Python 작성기를 사용한다.
- 기존 Node 두 인수를 명시한 호출은 개발용 호환 경로로 유지한다. 한 인수만 주면 오류다.
- 표시용 JSON을 입력으로 받아 Excel을 만들고 기존 저장본 검증기로 전 셀을 확인한다.
- 수식처럼 보이는 원문도 문자열로 보존한다. Excel 길이/표시 높이 한계를 넘으면 원문을 자르지 않고 실패를 기록한다.
- 기존 완료 기록, 저장 중 변경 검사, 새 폴더 사용, 실패 결과 다운로드 차단을 유지한다.
- 사용자용 출력은 같은 폴더의 `review_report.xlsx`와 `review_report.json`이다.

## PC 전달물

내부 시험용 ZIP에 필요한 Python 코드, 고정 프로필/체크리스트 초안, 설치·시작 명령, 사용 안내,
파일 해시 목록을 담는다. Git/가상환경/기존 출력/PDF/Node/기존 GridCell 실행기는 넣지 않는다.
압축 해제 위치에 Python 3.12 가상환경을 만들고 고정 requirements로 의존성을 설치한다.
최초 설치에는 패키지 다운로드가 필요하다. 실행 화면은 127.0.0.1에만 연결한다.

파일럿 지원 범위는 ZC_L02 ENG 체크리스트 근거 조사다. 자동 합격/불합격, 나머지 3개 agent,
모든 바이어/언어 지원과 실제 담당자 PC 설치 검증은 완료라고 표시하지 않는다.

## 검증

정상/빈 근거/수식형 텍스트/표시 한계/재실행 덮어쓰기/실패를 테스트한다.
기존 ZC 관찰을 재사용한 Python Excel과 기존 Excel의 전 셀·양식·JSON을 대조한다.
ZIP을 다른 한글·공백 경로에 풀어 새 PDF 실행과 Streamlit 결과 조회를 시험한다.
관련 집중 테스트, compileall, pip check와 배포 파일 해시 검사를 수행한다.
