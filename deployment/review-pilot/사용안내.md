# 매뉴얼 체크리스트 검토 파일럿

현재 제공 기능은 **ZC 영어 체크리스트 문구와 구성품 근거 조사**입니다.
일반 체크 59개 안에 구성품 항목이 있고, 구성품 상세 14개를 따로 보여줍니다.
문구를 찾았더라도 모델별 적용 여부와 합격/불합격은 아직 자동 판정하지 않습니다.
PDF 변경 비교, 회사 시스템 사양 확인, 다국어 의미·맞춤법 기능은 후속 개발 대상입니다.

## 처음 한 번 설치

1. ZIP 전체를 내 PC의 새 폴더에 압축 해제합니다. 예: `C:\ManualReview\pilot-20260915`.
2. `setup.cmd`를 더블클릭합니다. Python **3.12**와 최초 패키지 다운로드 연결이 필요합니다.
3. `Setup complete`가 나오면 설치 완료입니다. 이 폴더 전용 `.venv`를 사용합니다.

Python 실행기 `py`가 없는 경우 Python 3.12 터미널에서 `python setup_review.py`를 실행합니다.
회사 네트워크가 패키지 다운로드를 막으면 오류 내용을 개발 담당자에게 전달합니다.
검증된 압축 파일을 새 폴더에 다시 풀면 설치 실패 후 재시도할 수 있습니다.

## 매번 실행

1. `start.cmd`를 더블클릭합니다. 브라우저에 로컬 검토 화면이 열립니다.
2. `PDF로 새 체크리스트 검토 실행`에서 PDF의 전체 경로를 붙여 넣습니다. 원래 파일명을 유지하세요.
3. 결과 저장 위치를 확인하고 `체크리스트 검토 실행`을 누릅니다.
4. 완료되면 `통합 Excel 다운로드`를 누릅니다. 새 폴더에 저장된 파일을 직접 열어도 됩니다.
5. 사용을 마치면 실행 창에서 `Ctrl+C`를 눌러 종료합니다.

자동으로 브라우저가 열리지 않으면 `http://127.0.0.1:8501`에 접속합니다.
같은 PC에서 8501을 이미 쓰고 있다면 터미널에서 `start.cmd --port 8502`를 실행합니다.
다른 PC나 서버로 접속할 필요가 없습니다. 각 PC에서 실행합니다.
현재 원장 적용 파일럿은 ZC_L02 ENG에 한정됩니다. 다른 바이어 파일은 이 배포본으로 운영 검토하지 마세요.

## 결과 파일

```text
outputs/checklist_날짜_실행번호/
  review_report.xlsx     검토자용 Excel
  review_report.json     상세 데이터와 출처
  review_report_view.json / 완료 기록 / authoring.log
  _internal/             XML·MD·ReviewDocument·중간 근거
```

Excel은 Summary, Checklist Results, Item Results, Source Evidence 4시트입니다.
원문 위치는 PDF 페이지와 Source Evidence의 체크 ID/고정 항목 키로 찾습니다.
검토 메모는 **다운로드한 사본**에 적습니다. 프로그램이 보관한 원본 Excel을 수정하면 완료 기록과 달라져 재조회가 차단됩니다.
JSON과 내부 파일은 수정하지 마세요. 필요한 때 원인 조사에 사용합니다.
실패한 실행은 완료 결과로 표시하지 않습니다. 오류 문구와 해당 실행 폴더를 개발 담당자에게 전달하세요.

## 터미널 실행과 점검

압축 해제 폴더에서 실행합니다.

```powershell
.venv\Scripts\python.exe start_review.py --check
.venv\Scripts\python.exe review_cli.py "C:\Manuals\원래파일명.pdf" --output "C:\ReviewResults\새폴더"
```

Node나 개발용 Excel 작성 도구는 필요하지 않습니다. PDF와 처리 결과는 이 PC에 저장됩니다.
원본 PDF/체크리스트 내용은 외부 LLM API로 전송하지 않습니다.
설치 단계의 Python 패키지 다운로드는 별도입니다.

## 업데이트·복구

새 버전은 **새 폴더**에 압축 해제하고 설치합니다. 기존 프로그램 폴더와 결과를 덮어쓰지 않습니다.
문제가 있으면 이전 폴더의 `start.cmd`로 돌아갑니다. 설치 후 폴더를 옮기면 `.venv`가 깨질 수 있으므로 새 위치에서 다시 설치합니다.
`release_manifest.json`은 포함 파일의 버전/해시 목록이며 업무 승인이나 보안 서명은 아닙니다.
코드나 원장을 수정해야 할 때에는 개발 작업장에서 수정·검증한 후 새 ZIP을 생성합니다.

원본 PDF의 추출 누락과 다국어 의미 일치는 배포 동작 검사만으로 확인되지 않습니다.
ZC ENG/C-FRA MD 텍스트는 사용자가 2026-09-14 확인했으며 표지 연락처 제목의 굵게 표시는 후속 작업입니다.
