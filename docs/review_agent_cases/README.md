# 번역·편집 검토 에이전트 사례집

향후 에이전트 설계와 평가에서 사용할 실제 원문 사례다. 현재 추출기 규칙이나 체크리스트 DB가 아니다.
각 사례에서 **PDF와 추출문이 같은지**와 **원문 의미·편집·용어가 적절한지**를 따로 판정한다.
PDF대로 추출된 문구를 의미 검토 때문에 추출 오류로 돌리거나 임의 수정해서는 안 된다.

## CE_L05 — 사용자 판정 2026-09-14

[구조화 사례 6건](ce_l05_translation_editorial_cases.json)에 실제 문장 18개, 페이지/MCID/객체/경로,
source PDF hash, 기대 보고 내용, 사용자 의견을 보존했다. 사례 ID는 평가용으로 고정하지만,
XML 노드 ID와 경로는 원문 위치 근거일 뿐 고정 체크리스트 키가 아니다.
원문 문자열 자체가 Git에 저장되므로 ignored 출력 폴더가 없어져도 사례는 남는다.
이미지는 원본 PDF 페이지와 현재 crop 경로로 추적한다.

| 사례 | 추출 판정 | 미래 에이전트에서 보고할 내용 |
|---|---|---|
| CE-SOURCE-01 | 사용자 PASS | MON 벽 고리 높이 조건이 나사 규격 안내로 대체됨. 번역사가 제공한 의미 그대로 반영되었다는 사용자 의견 포함 |
| CE-SOURCE-02 | 사용자 PASS | MON 접지/보호 접지와 mains-lead 조건의 의미 확인. 로마/아라비아 숫자 표시 차이는 별도 처리 |
| CE-SOURCE-03 | 사용자 PASS | MON 스탠드/벽걸이 문맥 차이와 그림의 관계 |

이 PASS는 **원장 충실도에 대한 사용자 판정**이며 번역 정확성의 일괄 승인이 아니다.
향후 에이전트는 여섯 건을 보고 대상으로 찾아야 한다. 아직 해당 에이전트나 자동 보고 규칙을 구현한 것은 아니다.

## 기대 동작과 오탐 방지

- 원문과 추출문, 번역사 문구, 승인 용어집은 서로 다른 근거로 기록한다.
- 검토 보고서에 문장 쌍/페이지/차이/판단 근거/사용자 처리 상태를 함께 제시한다.
- CE-SOURCE-01의 번역사 원문 반영 여부는 사용자 제공 정보다. 번역사 파일을 직접 확인한 것으로 표시하지 않는다.
- CE-SOURCE-02에서는 II→2, I→1만으로 오류를 만들지 않는다. 클래스 값이 같고 표기 관례 차이일 수
  있다는 점을 먼저 고려한다. 해당 기술 문맥의 허용 표기는 승인 용어·스타일 기준으로 추가 확인한다.
  모양이 비슷한 I/l을 근거 없이 일괄 치환하지 않는다. 접지 의미 문제와 숫자 표기 문제도 분리한다.
- CE-SOURCE-06의 TRAMS는 사용자 제보 상태다. 정확한 KYR 승인 문자열·버전·제품 범위는 아직
  조회하지 않았다. 실제 접근 가능한 용어 근거 없이 LLM 번역을 '승인 용어'로 넣지 않는다.
- 적발 건수뿐 아니라 위 숫자 표기 음성 대조군(불필요한 경고를 내지 않아야 하는 사례)도 평가한다.
- PDF→XML→MD 내용은 그대로 유지한다. 사람에게 보일 교정 제안은 별도 결과로 만든다.

## 몽골 표기 조사 근거

몽골의 공식 맞춤법 자료 §64는 로마 숫자를 순서 표시 등에 사용하는 규칙을 명시한다.
따라서 '로마 숫자를 쓰지 않거나 뜻을 몰라서 1/2로 바꾼 것'이라고 추정할 근거는 없다.
이 매뉴얼 번역자의 선택 이유나 클래스 표기에 대한 별도 회사 규정은 확인하지 않았다.
[몽골어 공식 맞춤법 자료](https://toli.gov.mn/r)

Samsung 몽골어 공식 제품 사양은 `VESA бэхэлгээ`를 사용한다. CE PDF MON에서도 인접 문장은
VESA이므로, 같은 문맥의 VERSA는 몽골식 표기가 아닌 오타로 판단한다.
[Samsung 몽골어 공식 사양](https://www.samsung.com/mn/business/smart-signage/video-wall/vmt-lh46vmtubgbxci/)

## CE와 ZG ENG 제목 비교

동일 집계 기준에서 CE 23개, ZG 26개다. CE 23개는 ZG의 제목 문구·순서와 일치한다.
ZG에만 `Changing the TV’s password`(PDF p7), `Declaration of Conformity` 2개(p9/p10)가 있다.
두 선언서는 각각 Smart Control VG-TM2660/VG-TM2280 문서이므로 중복 추출이 아니다.
집계에 포함되지 않는 표지 제목·강조 소제목·표 내부 필드명은 별도로 검토한다.
전체 제목 문자열과 페이지는 사례 JSON의 `heading_comparison`에 함께 보존했다.
