# 통합 결과 조회와 단일 PDF 실행 연결

사용자가 승인한 단일 결과 폴더/통합 Excel/HTML 신규 생성 중단 방향을 실행한다. 추가 업무 기준 결정은 없으므로 기존 계속 진행 요청에 따라 구현한다.

## 결정

통합 읽기 화면은 이미 검증된 `read_completed_combined_review`를 사용한다. 폴더 입력 하나, 일반 체크와 구성품 상세 별도 표시, Excel 기본 다운로드와 내부 JSON 보조 다운로드를 제공한다. 다운로드 시에도 다시 검증한다. 기존 항목 화면과 실행 명령은 유지한다.

공통 실행은 새 결과 폴더 하나를 예약한다. `_internal/extraction`, `_internal/checklist`, `_internal/items`는 재현·진단 자료이며 사용자가 각각 입력할 필요가 없다. 최상위에 `review_report.xlsx`와 통합 JSON을 저장한다. PDF는 한 번 추출하며 두 관찰은 동일한 검증 묶음을 읽는다. 동일한 메모리 객체 공유가 아닌, 동일 추출본 공유다. 기존 묶음 재사용 옵션도 제공한다.

일반 관찰 완료 기록 v2는 JSON만 포함한다. 기존 v1의 HTML 포함 읽기 호환을 유지한다. 공통 실행은 HTML을 생성하지 않는다. 현재 통합 exporter의 새 폴더 보호를 유지하고, 실행 서비스가 예약한 폴더에 기록하는 내부 함수만 분리한다.

전체 실행 중에는 workflow lock으로 조회를 차단한다. 하위 관찰/Excel/마지막 입력 재검증 실패 시 최상위 failure 기록을 남겨 부분 결과가 완료로 소비되지 않게 한다. 기존 결과 폴더는 덮어쓰지 않는다. DB·추출 규칙·업무 판정은 현 상태를 유지한다.

## 대안 검토

임시 폴더에서 관찰한 후 버리는 방식은 추출 MD와 진단 자료를 다시 보관해야 한다. 각 관찰을 별도 최상위 폴더에 저장하는 방식은 사용자 요청과 맞지 않는다. 한 실행 폴더 아래 내부 자료를 모으는 방식을 선택한다.

## 검증 및 완료 범위

기존 통합 결과 조회, 조작/미완료 결과 거부, 화면 경로 변경 시 이전 다운로드 제거, 다운로드 재검증을 테스트한다. 새 PDF 1회 추출/묶음 재사용 0회 추출, 일반59·상세14, 입력 변경/실패 시 완료 차단, 신규 HTML 없음, 기존 HTML 완료 기록 호환을 확인한다. 실제 ZC PDF 실행과 기존 결과의 원문·관찰 동일성을 확인한다.

화면 PDF 업로드, 자동 업무 판정, 전체 PC 설치 배포, 사람의 PDF 품질 승인은 이 연결 완료와 별도로 기록한다.
