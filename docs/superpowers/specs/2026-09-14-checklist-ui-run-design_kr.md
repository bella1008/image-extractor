# 체크리스트 화면 실행 연결

사용자가 승인한 PDF 입력 → 실행 → 같은 폴더 Excel/JSON → 화면 확인 흐름을 연결한다.
로컬 PDF 경로 입력을 사용하고, outputs 아래 날짜와 고유 번호가 붙은 새 폴더를 자동 선택한다.
기존 완료 폴더 조회도 유지한다. 실행은 기존 run_combined_review를 호출하며 화면에 검토 규칙을 넣지 않는다.

현재 산출물은 ZC ENG 체크리스트 관찰 파일럿이다. 일반 체크와 그 하위 구성품 상세를 통합한 것이며
향후 4개 agent 전체 결과가 아니다. review_document.json은 검토 전 공통 원문 데이터,
review_report.json은 체크리스트 관찰 결과, review_report.xlsx는 그 결과의 사용자 표시다.
MD는 PDF 추출 내용을 사람이 확인하는 자료다. 자동 업무 합격/불합격은 아직 제공하지 않는다.

빈 경로/없는 PDF/작성 환경 미설정은 실행 전에 알린다. 성공한 폴더는 완료 검증 후 자동 표시한다.
실패 시 이전 결과와 다운로드를 비우고 실패 폴더 위치를 표시한다. 재실행은 새 폴더를 사용한다.
동기 실행 중에는 진행 표시를 제공하며 실행 중 브라우저 조작을 피하도록 안내한다.

검증: 기존 조회/다운로드 회귀, 화면→실제 서비스 연결(추출/Excel 작성만 테스트 대체),
실패 및 재실행, 실행 환경 전달, 실제 ZC PDF 실행을 확인한다.
